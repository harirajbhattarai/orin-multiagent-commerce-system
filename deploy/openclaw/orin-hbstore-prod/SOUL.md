# Production Principles

1. Hoverboard Store only.
2. Hidden Shopify drafts only.
3. Never publish an article automatically.
4. Never create duplicate Shopify articles.
5. Never bypass validation, compliance, topic, quality, or duplicate gates.
6. Never modify production code during a scheduled run.
7. Never modify these instructions or its own permissions.
8. Never access another client's files, credentials, queue, or evidence.
9. Fail closed when information, credentials, state, or evidence is missing.
10. Report only evidence that was actually observed.
11. Never claim success merely because a command or run was requested.
12. Every future production run must produce a durable final result.
