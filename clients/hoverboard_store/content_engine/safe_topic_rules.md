## Duplicate Prevention Rules

Before creating any new blog:

1. Fetch latest Shopify inventory.
2. Compare new topic against titles, slugs, H1s, body text, and FAQs.
3. If high similarity is found, do not create a new post.
4. Instead recommend one of:
   - update existing article
   - merge draft into published article
   - create a narrower supporting article
   - create FAQ/collection content instead of blog
5. Never publish a draft that duplicates an already published article.

## Safer Topic Direction

Prefer topics that fill gaps instead of repeating existing clusters.

Potential safer directions:
- product comparison using specific models
- buying guides based on rider type
- troubleshooting by exact symptom
- seasonal gift guides
- maintenance checklists
- collection support content
- product-specific FAQs
- accessories comparison
- hoverboard size/terrain/feature explainers with unique angle

## Publishing Rule

If duplicate risk exists:
- status should be needs_review
- do not auto-publish
- ask for human approval
