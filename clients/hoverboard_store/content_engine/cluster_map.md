# Hoverboard Store — SEO Cluster Map

Purpose:
This file controls blog topic clusters so ORIN does not create duplicate or overlapping content.

## Cluster Status Labels

- active = cluster has useful content and can receive supporting articles
- saturated = cluster already has enough broad content; avoid more generic posts
- needs_update = existing content should be refreshed before creating new content
- gap = opportunity for new content
- risky = high duplication risk
