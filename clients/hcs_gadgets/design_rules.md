# HCS Gadgets Article Design Rules

## Design Principle
Use the same backend article system as Hoverboard Store, but HCS Gadgets must have its own visual identity.

## Important Rule
Do not make HCS articles visually identical to Hoverboard Store articles.

## HCS Visual Direction
- Clean marketplace style
- Modern ecommerce look
- Practical product-discovery feel
- Neutral background sections
- Strong but simple CTA boxes
- Useful comparison/checklist blocks

## Suggested Colour Direction
Final colours can be changed later inside Shopify CSS.

Suggested starting system:
- Primary: dark navy / charcoal
- Accent: warm orange or electric blue
- Background: light grey / off-white
- Text: dark grey / black
- CTA: clean bold button style

## HTML Structure
Use brand-specific wrapper class:

<article class="hcs-article">
  ...
</article>

This allows HCS to have its own Shopify CSS without affecting Hoverboard Store or Aroma Haven.

## Shared SEO Structure
The article can use the same SEO logic:
- H1
- Intro
- quick answer box
- table of contents
- H2/H3 sections
- checklist or comparison block
- product/category CTA
- FAQs
- FAQ schema

## Brand-Specific Difference
Even if the SEO structure is similar, the visual design, colour, CTA wording, examples, and tone must be HCS-specific.
