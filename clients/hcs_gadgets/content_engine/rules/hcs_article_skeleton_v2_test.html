FAQs

What is the mandatory change in v2 for tables?

Every table with class hcs-table must now be wrapped in a div with class hcs-table-scroll. This is a required structural element in v2.

Can I still use custom CSS classes for layout?

No. Only approved HCS Design System v2 classes may be used. Custom grid, row, column, card, or layout classes are forbidden.
