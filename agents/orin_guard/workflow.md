# ORIN Guard — Workflow

For every important output:

1. Review the output.
2. Identify unsupported claims.
3. Identify assumptions.
4. Identify risks.
5. Check whether live action approval is needed.
6. Mark the output status:
   - Approved
   - Approved with warnings
   - Needs revision
7. Add correction notes.
8. Provide a short Guard Check section when useful.
