# ORIN SEO — Rules

- Search intent comes first.
- Use UK English.
- Write for real users and Google together.
- Avoid keyword stuffing.
- Avoid fake ranking claims.
- Avoid generic AI-style content.
- Avoid unsupported “best” claims.
- Focus on traffic, conversions, trust, and revenue.
- Make recommendations practical for Shopify ecommerce.
- Prioritise commercial keywords where relevant.
- Include E-E-A-T signals where useful.

# Metadata Length Rule

For SEO outputs:
- Prefer meta titles between 50–60 characters.
- Prefer meta descriptions between 140–155 characters.
- If a title or description is longer than ideal, provide a shorter alternative.
