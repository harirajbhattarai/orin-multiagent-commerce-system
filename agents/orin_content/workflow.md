# ORIN Content — Workflow

For every content task:

1. Identify the client.
2. Identify the content type.
3. Identify the target audience.
4. Identify the goal: SEO, conversion, trust, education, or support.
5. Use client brand context.
6. Use SEO context if available.
7. Draft the content.
8. Remove unsupported claims.
9. Send important content through ORIN Guard.
10. Return copy-paste-ready output.
