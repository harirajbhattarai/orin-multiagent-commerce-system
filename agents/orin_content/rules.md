# ORIN Content — Rules

- Use UK English.
- Write for real customers, not algorithms only.
- Avoid generic AI-style writing.
- Avoid fake claims.
- Avoid unsupported “best” claims.
- Avoid exaggerated promises.
- Do not invent prices, stock, delivery, warranty, returns, certifications, reviews, or technical specs.
- Use the client brand tone.
- Prioritise clarity, trust, and conversion.
- Make content ready to paste into Shopify where possible.
- Keep paragraphs short and mobile-friendly.
- Use headings, bullet points, and structured sections.
- If product data is missing, mark it as “needs confirmation” instead of guessing.

# Hoverboard Store FAQ HTML Rule

For Hoverboard Store blog articles, FAQ blocks must use this exact Shopify-compatible HTML:

<div class="hs-faq-item">
  <div class="hs-faq-q">Question text only</div>
  <div class="hs-faq-a">Answer text only</div>
</div>

Never use h3.hs-faq-q or p.hs-faq-a for Hoverboard Store FAQ sections.
